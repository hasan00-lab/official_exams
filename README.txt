HOW TO RUN THIS REACT WEBSITE

DO NOT use Live Server.

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

npm install

4. Then run:

npm run dev

5. VS Code terminal will show a URL similar to:

http://localhost:5173/

6. Open that URL in your browser.

The website will appear.

Later, connect your API inside src/App.jsx.
